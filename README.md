# YourNotes for Windows

Download the YourNotes desktop app: GitHub-style Markdown notes that live on your own computer.

**[⬇ Download the latest version](../../releases/latest)**

| File | What it is |
|---|---|
| `YourNotes-Setup.exe` | Installer. Adds YourNotes to the Start menu, with an uninstaller. |
| `YourNotes-Portable.exe` | One file that runs without installing, even from a USB stick. |

Windows 10 and 11, 64-bit. Free.

You can also use YourNotes in your browser, with nothing to install, at **https://yournotes-dev.netlify.app**.

## Installing

1. Download `YourNotes-Setup.exe` from the [latest release](../../releases/latest).
2. Run it. Windows may show a SmartScreen warning because the app isn't code-signed yet. Choose **More info → Run anyway**.
3. Pick the folder where your notes are, or should be, kept.

To uninstall, go to **Settings → Apps → Installed apps → YourNotes → Uninstall**. Your notes are plain `.md` files and stay where they are.

## About this repository

This repository only publishes the app. Each version is a [release](../../releases) with the two `.exe` files attached. They're built and uploaded automatically from the app's source code.
